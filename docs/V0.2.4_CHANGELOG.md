# V0.2.4 CHANGELOG

版本定位：**V1.3协议收口与相机本地数据面加固**。

## 协议边界

- 将 camera_module 对照版本统一为 `protocol_major=1`、`protocol_minor=9`、`abi_revision=17`；
- 将模块局部清单从 `interface_manifest.yaml` 改为 `camera_private_manifest.yaml`，避免和V1.3整机权威清单混淆；
- 明确 `CameraState/GetPoint3D/QueryCameraCapability/CaptureImage` 均为 `PRIVATE/LOCAL_ONLY`；
- 保留 `COMPONENT_CAMERA=7`、`DEVICE_NONE=255`、`HW_PTP_NONE`、`CLOSED_LOOP_CEREBELLUM` 的协议映射；
- 新增协议草案静态校验器，防止后续版本无意把私有端点改成PUBLIC。

## 数据面

- 新增 `frame_session_uuid`，写入私有状态、三维点查询结果和抓拍结果；
- streaming session 只在驱动 `start()` 成功后创建，一次重连对应一个新的UUID；
- 帧序号在新session从1重新开始，持久引用必须使用 `(session_uuid, sequence)`；
- Orbbec/RealSense深度值统一按 `min_depth_m/max_depth_m` 过滤，范围外写0；
- 清理 Orbbec 初始化中的重复 session/sequence 初始化。

## 工程化

- `build_orbbec.sh` 避免把当前工作空间旧driver作为underlay再次覆盖；
- 根目录不再包含编译后的 `test_orbbec_profiles` 二进制；
- Profile枚举源码移动到 `tools/orbbec_profile_probe.cpp`；
- 新增 `scripts/test_v024.sh`；
- 配置校验器增加深度范围、缓存、同步阈值等规则；
- Mock冒烟测试增加session UUID重建验证；
- 所有新增/修改代码补充中文注释，并保留原有注释语义。
