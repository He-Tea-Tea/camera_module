# 五、大脑如何调用？

重点：

大脑不能：

```python
import pyorbbecsdk
```

也不能：

```python
camera.open()
```

大脑只调用能力。

例如：

## 查询能力

大脑：

```text
QueryCameraCapability
```

得到：

```json
{
"name":"head_camera",
"rgb":true,
"depth":true,
"imu":true
}
```

---

## 获取三维点

大脑：

请求：

```text
GetPoint3D


u=320

v=240
```

小脑：

内部：

```text
CameraManager

↓

Adapter

↓

Depth SDK

```

返回：

```text
x=0.35

y=0.12

z=0.85
```

---

## 获取视觉数据

大脑订阅：

```text
/camera/head/rgb

/camera/head/depth

/camera/head/camera_info
```

不知道：

```text
Gemini
D435
```
